# 星见塔罗牌面资产规范（v1.0）

## 1. 当前范围

78 张原创牌面已全部完成并接入页面：22 张大阿卡纳 + 56 张小阿卡纳（含 16 张宫廷牌）。
每张牌均有唯一的 AI 生成母版、发布用 WebP 与 SVG 兼容回退，文件名与 `cards.js` 的卡牌 ID 一一对应
（`m00`–`m21`、`w01`–`w14`、`c01`–`c14`、`s01`–`s14`、`p01`–`p14`）。

牌面母版由 Google Gemini 图像生成模型按统一提示词批量产出，经逐张人工目检验收：
牌号与 `cards.js` 对应关系、花色元素数量、正位构图方向全部核对通过。

## 2. 画布与安全区

- 母版：`768 × 1376` JPG；发布用 WebP 统一缩放为 `600 × 1000`，比例 `3:5`，与页面牌面容器一致。
- 底部 `y=752..1000` 为标题安全区（248px），页面在此叠加牌名、正逆位与英文名；牌面图像不依赖内嵌文字表达牌义。
  分隔线（插图底边）在全部 78 张上统一于 `y=752`，与 SVG 回退里写死的 `line y=752` 一致。
- 逆位：页面只把牌面图像旋转 180°，牌名、正逆位标签和牌义保持正向可读，不交换牌名或关键词。
  因为安全区高度统一，逆位后顶部留白恒为 248px，不再随牌面变化。
- 牌面图像为装饰性内容，牌名与正逆位由 DOM 文本提供，避免图片替代可访问文本。

## 3. 视觉规则

- 统一深色星空底、金色细线框、紫金配色，与整站「星见 · 紫金星空」视觉语言一致。
- 大阿卡纳为叙事性中心构图；小阿卡纳数字牌以可数的花色元素表达牌义；宫廷牌为人物构图。
- SVG 回退为程序生成的统一装饰牌面（`scripts/build-card-deck.cjs`）：大阿卡纳显示罗马数字与星环，
  数字牌按数量排布花色符号，宫廷牌显示位阶文字与大花色符号。

## 4. 文件与格式

```
assets/cards/
  tarot-cards/   AI 生成母版 JPG（768×1376），不随页面发布、不进静态白名单
  masters/       早期 v0.1 的 6 张 SVG 样张母版（留档，已被 v1.0 取代）
  fallback/      发布用 SVG 兼容回退（78 张）
  webp/          发布用 WebP（78 张，600×1000，单张 ≤ 62KB（61,440B），合计约 3.7MB）
  manifest.js    页面加载清单（published = 78；每张含 bytes/sha256）
  ASSET_SPEC.md
  LICENSE.md
```

- 页面优先加载 WebP；不支持或加载失败时回退到 SVG；两者都失败时显示文字回退。
  加载失败会先带 `?retry=1` 重取一次 WebP（绕开损坏的旧缓存），再退 SVG——`<picture>` 的
  `<source>` 一旦被选中，失败时浏览器不会自动改用 `<img src>`，必须由脚本按序换源。
- 页面只在抽牌/翻牌后加载当前牌面，不预加载 78 张；`loading="lazy"` 与 `decoding="async"` 避免阻塞首屏。
- 体积预算：单张 WebP ≤ 62KB（61,440B），78 张总体积 ≤ 4MB（当前约 3.7MB）；首屏牌面请求数为 0。

## 5. 转换管线与修改记录

1. Gemini 按统一风格提示词生成 768×1376 JPG 母版 → `tarot-cards/`。
2. 逐张人工目检：牌号对应、元素数量、构图方向、边缘瑕疵。
3. Python/Pillow 转 WebP：边缘残白用深空色 flood-fill 修复（如 `m00` 整圈白边），
   缩放至 600×1000，quality 从 84 阶梯下调至单张 ≤ 62KB（61,440B）。
4. 标题安全区归一化（`scripts/normalize-card-safe-zone.py`）：AI 出图时底部留白高度并不一致
   （实测分隔线在 `y=668..807`，安全区 193~332px），直接旋转做逆位会让顶部留白逐张不同。
   该脚本保持金色边框（内框顶线 `ft`、内框底线 `y≈973~982`）不动，只把插图区 `[ft, b]` 垂直
   拉伸/压缩到统一分隔线 `y=752`，标题带按需裁切或用底色补齐。重采样用 BILINEAR（LANCZOS 的
   锐化会让重编码体积涨 10%~30%，顶穿单张预算）。拉伸系数 `k` 实测 0.929~1.131，中位 1.003。
5. `scripts/build-card-deck.cjs` 读取 `cards.js` 生成 78 张 SVG 回退、`manifest.js`（每张含 `bytes`/`sha256`）与 `LICENSE.md` 逐牌表。

- 修改记录：
  - v0.1.0（2026-10-28）建立规范、6 张 SVG 样张、三级回退机制。
  - v1.0.0（2026-10-29）78 张 AI 牌面全部接入，白边修复，回退与授权文档全量重建。
  - v1.0.1（2026-11-06）78 张 WebP 的标题安全区归一化，分隔线统一到 y=752（安全区 248px），修复逆位牌顶部留白不一致。
- 重新生成回退/清单只需 Node：`node scripts/build-card-deck.cjs`（读取既有 WebP，不转码）；JPG→WebP 转换是独立的人工/Pillow 步骤，不在该脚本内。
- 旧样张脚本 `scripts/build-card-assets.cjs` 只生成 v0.1 的 6 张样张；检测到 v1.0.0 清单时默认拒绝，确需覆盖必须显式加 `--force-replace`。
